# Autonomous Re-Sequencing — Fractal Pivot Chain (Criterion 1 evidence)

> **This demonstrates autonomous re-sequencing toward NEW evidence.** Starting from a
> C2 finding, the agent **pivoted to a different, related artifact it surfaced from the
> evidence** — the internal host that had contacted that C2 — and then investigated
> that host in depth. The next artifact at each step is the **model's own follow-up
> choice** (`follow_ups[].artifact_uri`), and every edge is a **real network
> co-occurrence in the carved pcap** — no invented links. So the investigation **plan
> adapts to what the agent finds**; it is not a fixed script.
>
> These ephemeral **fractal pivot agents** are distinct from the **60 persistent
> sensor micro-agents** (edr / suricata / yara / zeek / volatility …): the sensors run
> continuously and are never "spawned"; the pivot agents are short-lived, spawned on
> demand from a finding, and dissolve after reporting.

## Honest disclosure (what is real vs scaffolded)

- **Real:** the `Watcher` recursion; the SLM `pivot_infer` at every node (each a ~30–60 s
  CPU inference); the lineage; and **the model's own choice of the next artifact**
  (`follow_ups[].artifact_uri`). Every pivot edge is a **real pcap co-occurrence** in the
  carved evidence — **no invented edges**.
- **Honest scope of the claim:** the chain re-sequences across **2 distinct real
  artifacts** (C2 → host). The 3B CPU model (`Llama-3.2-3B-Instruct-Q4`, the only model
  on the box) reliably makes the C2→host pivot but tends to stay on the host rather than
  advance to a clean third distinct artifact, so depth 2 deepens the host investigation
  rather than moving to a fourth IP. We claim what is real: **one genuine
  artifact-to-artifact pivot plus depth**, not a 3-distinct-artifact chain.
- **Scaffolded for this artifact:** widened the per-pivot TTL (production is 2 s; CPU
  inference needs ~30–60 s) and took a single follow-up per level (`max_width=1`) for a
  clean linear path; production width is 16. The signed-ledger write requires the
  `findevil` service account's Ed25519 key (the running `findevil watcher` daemon does
  this in production); this capture proves the lineage without that key. Nothing in the
  chain is hand-authored.
